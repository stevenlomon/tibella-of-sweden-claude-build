## Dawn learnings (written to DAWN-THEME.md)

1. **`div:empty` hides purely visual elements** — Dawn's `base.css` has `div:empty { display: none }`. Progress bar fills, decorative divs with no text content get hidden. Fix: add `&nbsp;` with `font-size: 0`.

2. **Three Dawn JS mechanisms fight custom galleries:**
   - `media-gallery.setActiveMedia()` strips all `is-active` classes on variant change
   - `slider-component` ResizeObserver fires `initPages→update→slideChanged` loop on any display toggle
   - `scroll-trigger animate--fade-in` replays on each show
   - Fix: override `setActiveMedia`, no-op slider methods, strip animation classes

3. **`animationend` events silently fail** in Dawn's context even when animation runs. Use `setTimeout` instead.

4. **Crossfade with `position: absolute` breaks Dawn image sizing** — the old image briefly renders at collapsed size before absolute constraints apply. Use incoming-only animation instead.

5. **Specificity for `dt-slide-out`** must match or exceed the hide rule's ancestor chain (0,4,0 → needs 0,5,0).
