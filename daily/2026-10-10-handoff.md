## The core width problem

Dawn's `.page-width` class (defined in `base.css:84`) sets `max-width: var(--page-width)`. The theme's `page_width` setting in `config/settings_data.json` is **1200px**. Multiple custom sections wrap their content in an element with `class="page-width ..."`, which constrains them to 1200px centered.

The category cards section partially works around this — its CSS sets `.dt-collections__container` to `max-width: 1440px` and `width: calc(100% - 48px)` — but the `page-width` class in the Liquid still applies `max-width: 120rem` (1200px), and depending on CSS load order this may win.

**The first decision the next session must make:** How to give sections more width.

Options:
- **A) Increase `page_width` globally** in `settings_data.json` to 1440 or 1600. Simple, but affects every Dawn section (header, product grids, footer, etc.)
- **B) Remove `page-width` from custom section Liquid** and use custom container classes. Targeted, but needs a Liquid edit per section
- **C) Override `.page-width` within each section** via CSS specificity (`.dt-collections .page-width { max-width: 1440px }`). Already partially done for category cards, inconsistently applied elsewhere

Sections affected:
- `dt-collection-grid.liquid:8` — `class="page-width dt-collections__container"`
- `dt-tabbed-collection.liquid:12` — `class="page-width dt-tabbed-collection__container"`
- Hero is full-bleed (no `page-width` on outer) but the content uses `class="dt-hero__content page-width"` (line 35 of `dt-hero.liquid`)

## Section-by-section breakdown

### 1. Hero

**Files:** `theme/sections/dt-hero.liquid`, CSS lines 165–234 of `dt-dove-thistle.css`
**Mobile CSS:** lines 3080–3097

**What's there now:**
- `min-height: min(85vh, 780px)` — section and content container share this
- Heading: `font: 400 clamp(36px, 3.4vw, 58px)/1.18 Cormorant Garamond`, uppercase, `letter-spacing: 0.18em`
- Text positioned via `align-items: flex-end` on content container, `padding-bottom: 72px`
- Subtitle: italic Cormorant, `clamp(18px, 1.46vw, 28px)`
- CTA: underlined link, 13px Manrope uppercase

**What's wrong (per user + screenshots):**
- Heading is still too large at desktop widths — 58px max + 0.18em tracking creates a massive text block
- Text sits too high — the `padding-bottom: 72px` doesn't push it low enough. The Figma shows text in the lower ~20% of the hero
- Overall hero could be taller — the Figma shows more image breathing room above the text

**What to try:**
- Reduce heading max to ~48px: change `--tb-type-display-hero` clamp to something like `clamp(32px, 2.8vw, 48px)`
- Increase `padding-bottom` to 96px+ or use a larger `min-height` value
- Consider reducing `letter-spacing` from 0.18em to 0.12em — wide tracking on large text amplifies the "too big" feeling
- The `max-width: 680px` on `.dt-hero__copy` may need narrowing if the heading still feels wide

### 2. Category cards — "Shoppa efter kategori"

**Files:** `theme/sections/dt-collection-grid.liquid`, `theme/snippets/dt-collection-card.liquid`, CSS lines 1514–1596 and 2119–2192
**Mobile CSS:** lines 3274–3301

**What's there now:**
- Container: `width: calc(100% - 48px)`, `max-width: 1440px` (but `page-width` class also applied in Liquid)
- Grid: `display: flex`, `gap: 12px`, `overflow-x: auto`, `scroll-snap-type: x mandatory`
- Cards: `flex: 0 0 calc((100% - 48px) / 5)`, `min-width: 200px`, 4:5 portrait, 8px border-radius
- Heading: `clamp(20px, 1.5vw, 26px)`, 400 weight, uppercase, Cormorant
- Nav arrows: 40px circular buttons, right-aligned in header
- 6 cards defined (Kappor, Stickat, Klänningar, Väskor, Stövlar, Accessoarer) but only 5 visible without scrolling
- JS scroll navigation: prev/next buttons scroll by `card.offsetWidth + 12`

**What's wrong:**
- Cards don't extend to the visual edges — the section feels narrow compared to the full-bleed hero above it
- The rightmost card (5th visible) ends cleanly at the container edge — no peek/clip to signal that more cards exist to the right. Users won't know to scroll or click the arrow
- The `page-width` class in the Liquid (`dt-collection-grid.liquid:8`) may be fighting the CSS max-width override
- Heading font size could be smaller — the Figma shows a more understated section title

**What to try:**
- Remove `page-width` from the Liquid container class, or override it in CSS to ensure the 1440px+ max-width actually applies
- Make cards slightly narrower so 5 fit with a visible peek of the 6th: `flex: 0 0 calc((100% - 60px) / 5.3)` or similar
- Alternatively, allow the grid to extend past the container with negative margins + overflow visible on the right side only
- Consider reducing heading size further and/or using Manrope instead of Cormorant for this eyebrow-style heading

### 3. Tabbed collection — "Utvalt för säsongen"

**Files:** `theme/sections/dt-tabbed-collection.liquid`, CSS lines 2550–2630
**Mobile CSS:** lines 3336–3368

**What's there now:**
- Section: `padding: 80px 0`, `background: var(--tb-linne)` (warm cream)
- Container: uses `page-width` class (= 1200px max)
- Heading: `clamp(24px, 2vw, 34px)`, 400 weight, uppercase Cormorant, left-aligned
- Description: 15px Manrope, `color: var(--tb-sten)`, `margin-bottom: 24px`
- Tab pills: `padding: 10px 22px`, `border-radius: 100px`, 13px Manrope uppercase, active state = dark fill (`--tb-natt`)
- Grid: CSS grid `1fr 1fr 1fr` with 2 rows, first item spans `grid-row: 1 / 3` (bento layout), 16px gap
- Product cards render via Dawn's `card-product` snippet — currently showing boots (test products)
- Tab switching is visual only (toggles active pill class, doesn't filter products)
- Has a CTA section below the grid (currently empty — no button_label set in index.json)

**What's wrong:**
- The bento grid proportions look off — the featured card isn't dramatically taller than the 4 smaller ones. With `grid-template-rows: auto auto`, both rows auto-size to the product card's natural height, so the featured item is only 2× auto height
- The section is constrained to 1200px by `page-width`, making the whole section feel narrow
- Product card images (Dawn's default rendering) may not match the aspect ratio the Figma expects
- The gap between heading/pills and the grid could be tighter or looser depending on the Figma

**What to try:**
- Remove `page-width` from container or override max-width wider
- Consider explicit row heights: `grid-template-rows: 260px 260px` (or similar fixed values) so the featured card gets a defined 520px height
- Override Dawn's product card image ratio inside this section (`.dt-tabbed-collection__item .card__inner.ratio { --ratio-percent: 133% !important; }`)
- Consider a 2-column layout instead: large featured on the left (50%), 2×2 grid on the right (50%). This might better match the Figma's proportions

### 4. Editorial banner — "Utvalt för skandinaviska dagar"

**Files:** `theme/sections/dt-editorial-banner.liquid`, CSS lines 2242–2306
**Mobile CSS:** lines 3315–3325

**What's there now:**
- Full-bleed (no `page-width`), `min-height: 520px`
- Single image with `object-fit: cover`, absolute positioned to fill container
- Scrim: `rgba(30, 26, 27, 0.45)` flat overlay
- Text overlay: centered flex column, h2 with `max-width: 700px`, `font: var(--tb-type-display-banner)` = `400 clamp(38px, 3.75vw, 72px)/1.45 Cormorant`
- Heading is uppercase with `letter-spacing: var(--tb-tracking-display)` (0.18em)
- Body text: `max-width: 520px`, `clamp(14px, 0.9vw, 17px)/1.65 Manrope`
- CTA: white underlined link

**What's wrong:**
- The heading wraps to 3 lines: "UTVALT FÖR / SKANDINAVISK / A DAGAR" — the word "SKANDINAVISKA" breaks mid-word. At 72px max + 0.18em tracking + 700px max-width, the characters don't fit
- The section could be taller — 520px min-height feels squat under the product grid above
- The line-height of 1.45 on the heading creates excessive spacing between the 3 wrapped lines
- The background image may need a different crop or position adjustment

**What to try:**
- Increase `max-width` on the heading to 900px or wider — this should let the text fit on 2 lines
- Reduce heading max font-size from 72px to ~56-60px as a backup if the wider max-width isn't enough
- Reduce line-height from 1.45 to 1.2–1.3 for tighter multi-line heading
- Increase `min-height` to 600px+ for a more cinematic feel
- Check if the scrim opacity needs adjustment based on the image being used

### Safety rules
- **Always `cd theme/` before pushing**
- **Never use `--only`** — it silently wipes unlisted custom files from remote
- `locales/en.json` errors on push — harmless, needs manual upload via Shopify Admin
- Dev server: rename `en.json` to `en.json.bak` before `shopify theme dev`, restore after

### CSS architecture
- **`dt-dove-thistle.css`** (3500 lines): All custom section styles and tokens
  - Lines 1–108: `:root` token definitions
