2XL (EU 46) added to all eligible clothing products as of 2026-10-18 (Session 33).

**What was done:**
- 158 new variants across 57 products (all active clothing with S/M/L/XL sizing)
- Inventory set to 10 per variant at Tallbacken 26
- Size guide updated with 2XL row (bust 108–112, waist 90–94, hip 116–120)
- PRODUCT-IMPORT.md updated so future products default to S/M/L/XL/2XL

**Why:** Expanding size range to EU 46 for broader market reach.

**Skipped — supplier lacks 2XL reference data:**
- `hilda-suede-jacket` — supplier caps at L
- `thyra-turtleneck-dress` — supplier caps at L
- `hedda-oversized-cable-knit-pullover` — plus-size sourced (1XL–3XL), no standard 2XL reference
- `v-neck-knitted-cardigan` — supplier caps at XL (DRAFT)
- `thyra-elegant-knit-dress` — supplier caps at XL
- `marta-wide-leg-dress-pants` — supplier caps at XL

**Skipped — all pants/leggings:**
AliExpress "2XL" waist = 80–84cm vs Swedish 2XL (EU 52–54) = 105–117cm. 25–30cm gap makes reference measurements unusable. Bottoms cannot get 2XL until suppliers with real EU-standard sizing are found.

**How to apply:** When adding new products, include 2XL by default for tops/outerwear/dresses/sets. Skip 2XL for pants/leggings unless the supplier provides genuine EU-standard measurements.
